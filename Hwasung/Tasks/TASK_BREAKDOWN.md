# TASK BREAKDOWN

본 문서는 「장안문 VR 도슨트 - 시공간을 넘나드는 AI 역사 여행」 프로젝트를 언리얼 엔진 환경에서 실제 제작하기 위한 작업 분해 문서이다. 공모전 제출용 기획서와 동일한 방향을 유지하되, 구현 우선순위와 검증 기준이 바로 보이도록 프리프로덕션, 연출 구현, AI 연동, 최적화, 시연 준비 순서로 정리한다.

## 1. 작업 목표

- 장안문 단일 공간을 중심으로 한 고품질 VR 역사 해설 콘텐츠 구현
- 5개 핵심 시퀀스 기반 시네마틱 연출 완성
- 친화형 3D AI 도슨트 및 3D UI 시스템 구현
- 텍스트 입력 기반 실시간 Q&A 기능 구현
- 공모전 시연 가능한 수준의 안정적 데모 빌드 확보

## 2. 개발 원칙

- 수원화성 전체 확장보다 장안문 단일 공간 완성도를 우선한다.
- 언리얼 엔진 5 기반의 시퀀서, 라이팅, UMG, 블루프린트 중심으로 빠르게 프로토타이핑한다.
- 시연 영상과 실시간 체험이 모두 가능한 구조로 설계한다.
- AI는 단순 제작 도구가 아니라 사용자와 상호작용하는 도슨트 역할로 구현한다.
- 공모전 제출 일정 기준으로 “보여줄 수 있는 완성도”를 우선 확보한다.

## 3. 단계별 작업 분해

### Phase 1. 프리프로덕션 및 기본 환경 구축

#### Task 01-1. 프로젝트 구조 세팅

목표:
- 언리얼 엔진 5 프로젝트 생성 및 폴더 구조 표준화

작업 내용:
- 콘텐츠 폴더를 Environment, Character, UI, Sequence, Blueprint, Material, FX, Audio, API 등으로 분리한다.
- 장안문 관련 레벨과 시연용 메인 레벨을 분리 설계한다.
- 향후 데모 빌드 기준 플랫폼 설정과 기본 렌더링 옵션을 정의한다.

완료 기준:
- 팀원이 동일한 구조로 에셋과 블루프린트를 추가할 수 있다.
- 메인 레벨과 테스트 레벨이 분리되어 있다.

#### Task 01-2. 장안문 에셋 수집 및 배치

목표:
- 장안문 중심 공간의 기본 월드 구성 완료

작업 내용:
- 장안문 외부 전경, 옹성, 홍예문, 성벽 상부 공간이 포함된 기본 맵을 구성한다.
- 스케일 검증을 위해 VR 기준 플레이어 높이와 이동 기준점을 배치한다.
- 문화재 구조상 중요한 시점 위치를 마커로 지정한다.

완료 기준:
- 5개 핵심 시퀀스가 모두 같은 레벨 안에서 연결 가능하다.
- 카메라 기준 주요 뷰포인트가 명확히 정리되어 있다.

#### Task 01-3. 기본 라이팅 리그 구축

목표:
- 아침, 실내 강조, 야간 연출이 가능한 라이팅 기반 구축

작업 내용:
- Directional Light, Sky Atmosphere, Sky Light, Exponential Height Fog 기본 세팅
- 홍예문 내부용 Spot Light 세팅
- 야간 전환용 Point Light 또는 Rect Light 배치
- 라이트 시나리오 전환 가능 여부 테스트

완료 기준:
- 아침/실내/야간 톤을 각각 재현할 수 있다.
- 장안문 석재, 목재, 기와 재질이 라이팅에 정상 반응한다.

### Phase 2. AI 도슨트 및 인터랙션 기반 구현

#### Task 02-1. AI 도슨트 캐릭터 구현

목표:
- 친화형 3D 도슨트 캐릭터의 기본 비주얼과 동작 구현

작업 내용:
- 분홍색 둥근 캐릭터 모델 또는 대체 마스코트형 메시 적용
- Rubber 질감 기반 머티리얼 제작
- Idle, Jump, Point, React 등 기본 애니메이션 상태 구성
- 느낌표/물음표 파티클 이펙트 연결

완료 기준:
- 캐릭터가 장면별로 최소 4종 이상의 반응을 표현한다.
- 캐릭터 재질이 과도한 반사 없이 부드러운 질감으로 표현된다.

#### Task 02-2. 3D UI 패널 및 타이핑 연출 구현

목표:
- 월드 스페이스 기반 해설 UI 구현

작업 내용:
- 1:1 비율의 정사각형 UMG 패널 제작
- 텍스트 출력용 타입라이터 애니메이션 구현
- 캐릭터 근처 또는 화면 전면 Anchor 기준 위치 제어
- 장면별 고정 대사 데이터 구조 설계

완료 기준:
- UI가 VR 또는 3D 공간 기준에서 읽기 가능한 크기로 출력된다.
- 텍스트가 즉시 노출되지 않고 단계적으로 출력된다.

#### Task 02-3. 사용자 입력 구조 설계

목표:
- 시네마틱 진행과 자유 질문 모드를 구분하는 입력 체계 설계

작업 내용:
- 시퀀스 재생 중 입력 제한 범위 정의
- 자유 Q&A 구간에서 텍스트 입력을 받을 수 있는 UI 설계
- 향후 VR 컨트롤러 또는 키보드 입력 대응 방식 검토

완료 기준:
- 시네마틱 감상과 인터랙션 모드가 충돌하지 않는다.
- 질문 입력 UI가 독립적으로 호출 가능하다.

### Phase 3. 시네마틱 시퀀스 제작

#### Task 03-1. 시퀀스 1 인트로 제작

목표:
- 장안문 외부 상공 하강 인트로 완성

작업 내용:
- 옹성과 누각 전체를 보여주는 카메라 경로 제작
- 캐릭터 낙하/착지 애니메이션 배치
- 인트로 환영 대사 UI 연동

완료 기준:
- 장안문의 규모감이 첫 장면에서 즉시 전달된다.
- 캐릭터 등장과 대사 출력 타이밍이 자연스럽다.

#### Task 03-2. 시퀀스 2 옹성 해설 제작

목표:
- 옹성의 방어 구조를 직관적으로 이해시키는 장면 완성

작업 내용:
- 옹성 내부 진입 경로와 총안 클로즈업 카메라 구성
- 압박감 있는 구도와 벽면 강조 라이팅 조정
- 캐릭터 포인팅 애니메이션 및 설명 문구 연결

완료 기준:
- 사용자가 옹성의 함정 구조를 시각적으로 이해할 수 있다.
- 설명 대상인 총안 위치가 명확히 드러난다.

#### Task 03-3. 시퀀스 3 홍예문 해설 제작

목표:
- 홍예문 천장 단청의 상징성을 강조하는 장면 완성

작업 내용:
- 홍예문 내부 진입 후 틸트 업 카메라 제작
- 황룡/청룡 텍스처 또는 단청 디테일 노출 최적화
- 스팟 라이트 기반 강조 연출 구성
- 캐릭터 리액션 및 감탄형 UI 대사 연결

완료 기준:
- 천장 문양이 장면의 핵심 오브젝트로 선명하게 보인다.
- 실내 어둠과 포인트 조명의 대비가 충분하다.

#### Task 03-4. 시퀀스 4 야경 연출 제작

목표:
- 장안문의 건축미와 야간 분위기를 강조하는 장면 완성

작업 내용:
- 노을에서 야간으로 전환되는 타임랩스 구현
- 처마 및 성벽 조명의 순차 점등 연출 제작
- 석재, 기와, 목재 재질 반응값 최종 보정
- 캐릭터 감상 모션 및 야경 해설 문구 연결

완료 기준:
- 시간 변화가 부자연스럽지 않다.
- 조명 점등 후 장안문 질감이 충분히 살아난다.

#### Task 03-5. 시퀀스 5 자유 Q&A 구간 제작

목표:
- 시네마틱에서 상호작용 체험으로 자연스럽게 전환

작업 내용:
- 성벽 위 프리 카메라 또는 자유 시점 전환 구현
- 대기 모션 캐릭터와 질문 유도 문구 배치
- 질의응답용 UI 진입 트리거 구성

완료 기준:
- 마지막 장면에서 사용자가 자유롭게 질문할 준비 상태가 된다.
- 연출 모드 종료와 인터랙션 모드 시작이 명확히 구분된다.

### Phase 4. LLM 연동 및 응답 시스템 구축

#### Task 04-1. API 통신 블루프린트 구축

목표:
- 외부 LLM과 연결되는 기본 비동기 통신 구조 구현

작업 내용:
- HTTP Request/Response 처리 로직 구성
- 질문 텍스트 전송 및 JSON 응답 수신 구조 구현
- 예외 상황에 대한 실패 처리 메시지 정의

완료 기준:
- 사용자가 입력한 질문이 API로 전달된다.
- 응답 성공/실패 상태를 UI에서 구분할 수 있다.

#### Task 04-2. 응답 파싱 및 UI 렌더링

목표:
- AI 응답을 3D UI에 즉시 반영

작업 내용:
- JSON 응답에서 표시 대상 텍스트 추출
- 타입라이터 출력과 연동
- 장문 응답의 줄바꿈 및 패널 크기 처리 규칙 정의

완료 기준:
- 응답 텍스트가 지연 없이 읽기 가능한 형식으로 노출된다.
- UI 오버플로우나 비정상 레이아웃이 발생하지 않는다.

#### Task 04-3. 도메인 제한형 프롬프트 설계

목표:
- 장안문 및 수원화성 맥락에 맞는 답변 품질 확보

작업 내용:
- 역사·건축·상징 중심의 도슨트 역할 프롬프트 설계
- 허위 정보 최소화를 위한 답변 범위 제한 문구 정의
- 초등/일반/관광객 관점에 맞는 톤 조정 가능성 검토

완료 기준:
- 질문에 대한 답변이 장안문 맥락에서 벗어나지 않는다.
- 과도하게 일반적인 답변 비율이 낮다.

### Phase 5. 시각 품질 개선 및 최적화

#### Task 05-1. 머티리얼 및 텍스처 품질 조정

목표:
- 장안문의 문화재 질감을 설득력 있게 표현

작업 내용:
- 석재, 목재, 기와, 단청 재질의 Base Color, Roughness, Metallic 값 조정
- 야간 조명에서 과도한 반사나 플리커 여부 점검
- 카메라 근접 구간 위주로 텍스처 디테일 우선 보정

완료 기준:
- 핵심 클로즈업 장면에서 재질 표현이 어색하지 않다.
- 장면 전환 시 톤 불일치가 크지 않다.

#### Task 05-2. 퍼포먼스 최적화

목표:
- 공모전 시연용 안정 프레임 확보

작업 내용:
- 불필요한 메시, 그림자, 파티클, 후처리 효과 정리
- 시퀀스별 성능 병목 지점 점검
- 데모 장비 기준 렌더링 옵션 조정

완료 기준:
- 시연 구간에서 프레임 드랍이 체감되지 않는다.
- 핵심 장면 품질을 유지하면서도 안정적으로 구동된다.

#### Task 05-3. 전환 흐름 및 사용자 경험 보정

목표:
- 장면 간 연결과 체험 흐름 정리

작업 내용:
- 시퀀스 간 전환 템포 조정
- 대사 길이와 카메라 체류 시간 균형 조정
- 질문 유도 문구와 자유 탐색 시간 최적화

완료 기준:
- 해설 흐름이 끊기지 않는다.
- 사용자가 지루하거나 급하다고 느끼는 구간이 줄어든다.

### Phase 6. 시연 준비 및 제출 패키지화

#### Task 06-1. 시연 영상 캡처

목표:
- 공모전 제출용 핵심 데모 영상 확보

작업 내용:
- 5개 시퀀스를 하나의 흐름으로 캡처
- UI, 캐릭터, 라이팅, 연출이 가장 잘 보이는 카메라 기준 확정
- 필요 시 자막 또는 요약 캡션 추가

완료 기준:
- 기획서 내용과 정확히 대응되는 영상 결과물이 있다.
- 심사위원이 핵심 기능을 1회 시청으로 이해할 수 있다.

#### Task 06-2. 발표 자료 및 설명 자료 정리

목표:
- 신청서, 기술설명서, 발표 자료 간 메시지 일치

작업 내용:
- 프로젝트 개요, 차별점, 구현 기술, 기대 효과 문안 통일
- 시퀀스 구성과 기술 요소를 발표용 요약 자료로 재정리
- 예상 질의응답 포인트 사전 정리

완료 기준:
- 문서 간 표현 충돌이 없다.
- 심사 대응용 핵심 메시지가 한 문장으로 정리 가능하다.

#### Task 06-3. 최종 데모 빌드 및 점검

목표:
- 현장 시연 가능한 최종 버전 확정

작업 내용:
- 시작부터 인트로, 해설, 자유 Q&A까지 전체 플로우 점검
- 네트워크 응답 실패 시 대체 메시지 동작 확인
- 실행 파일, 에셋, 설정 파일 포함 여부 최종 검수

완료 기준:
- 현장 시연 중 치명적 중단 없이 전체 흐름이 재생된다.
- 최소 1회 이상 리허설을 통과한 빌드가 준비된다.

## 4. 우선순위

### 최우선 구현

1. 장안문 맵 구성
2. 5개 시퀀스 카메라 연출
