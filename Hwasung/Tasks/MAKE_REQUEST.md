# 사용 요청
~~~~
아래 내용을 기준으로 `docs/PLANS.md`에 신규 작업 리스를 1건 추가해줘.

중요 조건:
- 작업 대상 레벨은 `DEMO` 레벨이다.
- 별도 언급이 없는 한 모든 구현과 검증은 `DEMO` 레벨 기준으로 진행한다.
- 작업이 기존 단계 순서와 맞지 않거나 범위가 과도하면 바로 진행하지 말고 먼저 이유를 설명해줘.

목표:
- 장안문 외부 상공 하강 인트로 완성

작업 내용:
- 옹성과 누각 전체를 보여주는 카메라 경로 제작
- 캐릭터 낙하/착지 애니메이션 배치
- 인트로 환영 대사 UI 연동

완료 기준:
- 장안문의 규모감이 첫 장면에서 즉시 전달된다.
- 캐릭터 등장과 대사 출력 타이밍이 자연스럽다.
